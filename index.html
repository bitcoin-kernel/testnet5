Rules, not trust
Proof of work, difficulty with no 20-minute exception, scripts, and BIP54's cleanups: timewarp, 64-byte transactions, coinbase locktime, sigop limit.

    
Small enough
Testnet5 is a few thousand blocks, so the whole set of unspent coins fits in a tab. No snapshot, nothing to trust about the starting point.

    
Kept locally
Blocks stay in this browser. A reload checks them again from the local copy and only fetches what is new.
